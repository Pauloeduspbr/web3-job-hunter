# Web3 Job Hunter — Automated Job Search & Application

Automated pipeline for finding and applying to **Web3/FinTech/Crypto Data Engineer** remote positions and **Superteam Earn** bounties.

## What This Does

- **Job Discovery**: Automated search across Web3 job boards, LinkedIn, and crypto-native platforms
- **Smart Matching**: Scores job postings against my skill profile (Python, SQL, Spark, Airflow, dbt, AWS/GCP)
- **Application Assets**: Maintains optimized resumes, cover letters, and interview prep materials
- **Bounty Tracking**: Monitors Superteam Earn for data engineering bounties
- **Portfolio Integration**: References live projects as proof of work
